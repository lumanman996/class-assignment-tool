分班设置

班名格式中 {n} 代表班号，{nn} 代表两位班号（01、02…），{年级} 代表上面填的年级。

水平相同的学生谁先谁后由随机种子决定。同一份名单、同样的设置、同一个种子，得到的结果完全相同。

班主任名单（可选）

每行一位，人数需与班级数量相同。分班后可在结果页随机抽签决定每位班主任带哪个班。

      使用说明

      五个步骤

      1. 导入：拖入 Excel 名单。工具自动识别姓名、性别和成绩列，可以手动增减科目。表头不在第一行时，改「表头在第几行」。
      2. 设置：填年级、班级数量、班名格式。
      3. 约束：有「必须同班」「必须分开」「指定班级」的要求就在这里添加，没有就跳过。
      4. 结果：查看均衡评分和各班名单，可手动调班。
      5. 导出：导出 Excel、打印名单和公示、保存方案文件。

      常见问题

      • 有学生缺成绩怎么办？照常导入。缺的科目不计入均衡，学生按其余科目的水平分班。
      • 没有成绩能分班吗？能。一科都不勾选，工具只保证各班人数和男女均衡，其余随机。
      • 科目满分不一样会不会不公平？不会。各科先换算成标准分再比较，150 分和 100 分的科目同等对待。
      • 随机种子是什么？决定同水平学生先后顺序的一个数字。名单、设置、种子都相同，结果就完全相同，便于复核。
      • 重名学生怎么区分？名单和调班窗口都显示「原表行号」，即学生在 Excel 中的行号。
      • 调班后均衡会变差吗？用「对调」基本不变；「仅移动」会改变两个班的人数。每一步都可以撤销。
      • 关掉程序数据会丢吗？会。在导出页点「保存方案文件」，下次用「载入方案」恢复。
      • 导出的文件在哪里？都在 output 文件夹里，导出页有「打开这个文件夹」按钮。PDF 生成后会自动打开。
      • 想先试试怎么办？在导入页点「载入演示数据」，会载入 257 名虚构学生，其中有两对双胞胎（欧阳、司马）和几名缺成绩的学生，可以用来试约束和调班。
      • 数据会上传吗？不会。所有计算都在这台电脑上完成。程序只在检查更新时访问 GitHub，不发送任何名单数据；不联网也能正常使用。
      • 怎么更新？有新版本时右上角会出现「有新版本」按钮，点它再点「立即更新」即可。也可以点下面的「检查更新」。
