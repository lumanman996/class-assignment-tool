# 匀班 算法说明

本文用通俗的语言说明匀班是怎么分班的。实现见 [`algo.js`](../yunban/ui/algo.js)。

## 一句话概括

先像发牌一样按成绩高低轮流把学生发到各班，再让电脑反复尝试"两个班各换一个人"，只要换完更均衡就保留。

## 第一步：算出每个学生的综合水平

各科的满分和难度不同，直接加总分会让分值大的科目说了算。所以先把每科成绩换算成**标准分**：

> 标准分 = （该生成绩 − 全体平均分）÷ 全体标准差

标准分表示"比平均水平高或低多少"，150 分的科目和 100 分的科目由此可以对等比较。

综合水平 = 各科标准分的加权平均。缺考的科目不参与计算；一科成绩都没有的学生按平均水平对待。

## 第二步：蛇形发牌

男生、女生各自按综合水平从高到低排队，水平相同的由随机种子决定先后。然后按 S 形路线发到各班：

```
第 1 轮：1班 → 2班 → 3班 → 4班
第 2 轮：4班 → 3班 → 2班 → 1班
第 3 轮：1班 → 2班 → 3班 → 4班
……
```

来回折返是为了避免某个班总是先挑。男女分开发，保证每个班男女人数相当。人数不能整除时，男生多出来的人和女生多出来的人会落在不同的班，所以各班总人数最多相差 1 人。

## 第三步：落实约束

如果设置了约束条件，在发牌结果上调整：

- **指定班级 / 必须同班**：把相关学生换到目标班。每换进一个人，就从目标班换出一个**同性别、水平最接近**的学生，尽量不影响均衡。
- **必须分开**：同班的成员中留一个，其余用同样的办法换到没有本组成员的班。

这些学生之后不再被第四步移动。互相矛盾的约束会直接报错。

## 第四步：交换优化

蛇形发牌只看综合水平，单科之间仍可能有差距。于是电脑进行几万到几十万次尝试：

1. 随机挑两个不同班、同性别的学生；
2. 假设两人对调，计算各班是否更均衡；
3. 更均衡就对调，否则放弃。

"均衡"的衡量标准是：每个班每一项的平均值与全年级平均值的差距（同样按标准差换算），所有班、所有项加起来越小越好。参与衡量的项包括：

- 每一门勾选的科目（乘以各自的权重）；
- 总分（只统计成绩齐全的学生）；
- 每个需要打散的类别，例如"来自某小学的学生占比"。

因为只在同性别之间对调，这一步不会改变各班的人数和男女构成，也不会破坏约束。

## 均衡评分怎么算

结果页的评分从 100 分起扣：

- 每一项成绩：班级间平均分差距 ÷ 该项学生成绩的标准差，取各项的平均值，每 1% 扣 1 分；
- 班级人数、男生人数、女生人数：班级间差距超过 1 人的部分，每人扣 3 分。

例如某科学生成绩标准差是 12 分，各班平均分最多相差 0.24 分，这一项的差距就是 2%。

## 可复现性

整个过程只有两处用到随机：同水平学生的排序、交换优化时挑选学生。两者都由随机种子驱动，所以名单、设置、约束、种子都相同时，结果完全相同。

手动调班和班主任抽签不在此列：手动调班记录在方案文件里；抽签结果由种子和抽签次数决定。

## 实测效果

仓库自带的测试（`node tests/test_algo.js`）覆盖以下场景，8 个班：

| 场景 | 各科平均分的班级间差距 |
|---|---|
| 402 人，语数英三科 | 0.04～0.10 分 |
| 613 人，六科，满分 150/100/50 混合，5% 缺考 | 0.06～0.26 分 |
| 同上，再加 7 条约束和毕业学校打散 | 各科均在满分的 1.5% 以内，同校学生各班最多相差 2 人 |
| 无成绩模式 | 人数、男、女各班最多相差 1 人 |
