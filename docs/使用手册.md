# 匀班 使用手册

打开匀班（Windows 双击 `匀班.exe`，Mac 双击 `匀班`），按界面顶部的五个步骤依次操作。已完成的步骤可以随时点回去修改。

## 先试一试

手头没有名单时，在导入页点「载入演示数据」，会载入 257 名虚构的七年级学生。里面有两对双胞胎（欧阳文轩与欧阳文昊、司马若兰与司马若竹）可以用来试约束，还有 4 名缺成绩的学生和 5 组重名学生。

## 准备名单

名单是一份 Excel 文件（`.xlsx`、`.xls` 或 `.csv`），每个学生一行。

| 列 | 是否必须 | 说明 |
|---|---|---|
| 姓名 | 必须 | 为空的行不参与分班 |
| 性别 | 必须 | 男/女、男生/女生、M/F 都可以；认不出的行不参与分班 |
| 成绩 | 可选 | 任意科目、任意数量。空白或"缺考"视为缺成绩 |
| 其他 | 可选 | 学号、毕业学校、原班级等，会原样带到结果里 |

表格上方有标题行也没关系，工具会自动找到表头；找错了可以手动改「表头在第几行」。

## 第 1 步：导入名单

1. 把文件拖进虚线框，或点「选择文件」。
2. 确认「姓名」「性别」对应的列。
3. **成绩科目**：工具已自动勾选成绩列，可以增减。学号、总分、排名这类数字列默认不勾。
   - 权重一般保持 1。某一科特别重要时可调大。
   - 一科都不勾 = 无成绩模式，只保证人数和男女均衡，适合小学一年级。
4. **打散类别**（可选）：勾选「毕业学校」「原班级」等，同一类别的学生会平均分到各班。
5. 查看下方提示：
   - 红色「异常」行不参与分班，需要回 Excel 修正后重新导入。
   - 黄色「缺部分成绩」的学生**照常参与分班**，按其余科目的水平安排。

## 第 2 步：分班设置

| 设置 | 说明 |
|---|---|
| 年级 | 如"七年级""高一"，用于班名和打印件标题 |
| 班级数量 | 2～40 |
| 班名格式 | `{n}` 是班号，`{nn}` 是两位班号，`{年级}` 是年级。例：`{年级}（{n}）班` → 高一（1）班；`7{nn}班` → 701班 |
| 随机种子 | 决定同水平学生的先后顺序。记下它，以后可以复现同一结果 |
| 均衡优化 | 建议保持勾选 |
| 班主任名单 | 可选。每行一位，人数与班级数相同，分班后可抽签 |

没有约束条件的话，点「跳过约束，直接分班」。

## 第 3 步：约束条件（可选）

成绩之外的硬性要求。电脑先满足这些要求，再做均衡。

| 类型 | 含义 | 例子 |
|---|---|---|
| 必须同班 | 选中的学生分到同一个班 | 双胞胎要求同班 |
| 必须分开 | 选中的学生两两不同班 | 双胞胎要求分开 |
| 指定班级 | 选中的学生进指定的班 | 行动不便的学生安排在一楼的班 |

添加方法：选类型 → 在「添加学生」里输入姓名并从下拉中选中（重名学生看行号）→ 需要的话填备注 → 点「添加这条约束」。

互相矛盾的约束（比如同一批学生既要同班又要分开）会在分班时提示，不会给出错误结果。

## 第 4 步：分班结果

- **均衡评分**：0～100 分，95 以上为优。右侧条形图显示每一项在班级之间的最大差距，越短越好。
- **均衡表**：每班的人数、男女、各科平均分，最后一行是班级间差距。
- **两种视图**：
  - 单班表格：一次看一个班，含每科成绩。
  - 全部班级并排：所有班一屏展示，可以拖动学生。
- **调班**：
  - 表格里点「调班」，或在并排视图里点学生。推荐用「对调」，工具会从目标班找出同性别、水平最接近的学生换回来。
  - 并排视图里，把学生拖到另一名学生身上是对调，拖到班级空白处是移动。
  - 「撤销最后一步」可以一步步退回去。
  - 调班后如果破坏了约束，页面会用黄色提示。
- **班主任抽签**：填了班主任名单后可用，可以多次抽。
- 对结果不满意：点「换个种子重新分班」。

## 第 5 步：导出

| 导出内容 | 说明 |
|---|---|
| 分班结果 Excel | 总名单（原表所有列 + 班级 + 班内序号）、每班一个工作表、均衡统计 |
| 分班报告 PDF | 带图表的完整报告。第一页是总览：均衡评分、各班情况、人数和平均分图表、分班设置；之后每班一页。可选是否包含学生成绩 |
| 各班名单 PDF | 每班一页，含序号、姓名、性别、备注栏 |
| 编班结果公示 PDF | 编班方法、各班情况、各班名单。可选择是否显示平均分、是否列出约束与手动调整的数量 |
| 方案文件 | 保存当前全部状态，以后用右上角「载入方案」恢复 |

「班内排序」决定名单先后和班内序号，可选按姓名、按成绩、按原表顺序。各班名单和公示只含姓名和性别，不含个人成绩。

**导出的文件在哪里**：都保存在 `output` 文件夹里（Windows 在程序所在文件夹下，Mac 在"文稿 / 匀班"下），导出页有「打开这个文件夹」按钮。PDF 生成后会自动打开。同名文件会被新的覆盖。

生成 PDF 用的是电脑上已有的 Edge 或 Chrome，不用另外安装。如果电脑上两者都没有，会改存为网页文件，打开后可以在浏览器里打印。

## 试用与激活

下载的安装包第一次打开起免费试用 3 天，试用期内功能不受限制。试用结束后仍然可以分班、查看结果、保存方案；导出 Excel 和 PDF 需要激活。

在界面右上角点「输入激活码」，把显示的机器码发给管理员，收到激活码后粘贴进去点「激活」。激活码只对这台电脑有效，换电脑需要重新申请。

## 常见问题

**关掉程序后数据还在吗？**
不在。需要保留的话，在导出页保存方案文件。

**重名学生怎么区分？**
看「原表行号」，即学生在 Excel 中的行号。

**为什么有的班多一个人？**
总人数不能被班级数整除时，各班人数最多相差 1 人。

**满分不同的科目会不会不公平？**
不会。各科先换算成标准分再比较，详见 [算法说明](算法说明.md)。

**数据会上传吗？**
不会。名单只在这台电脑上处理。程序只在检查更新和下载新版本时访问 GitHub，不发送任何名单数据；不联网也能正常使用。

**怎么更新到新版本？**
有新版本时，界面右上角会出现「有新版本」按钮。点它，再点「立即更新」，程序会自己下载、换上新版并重新打开，导出的文件和激活状态都不受影响。也可以在「使用说明」底部点「检查更新」。下载不下来时，点「打开下载页面」手动下载。

**方案文件能发给别人吗？**
可以，对方用「载入方案」就能看到完全相同的结果。注意文件里有完整的学生名单。
