# 七年级新生分班工具

本地网页工具：导入学生 Excel 名单，按**蛇形分班法**自动分班，保证各班**语文/数学/英语平均分、总分平均分、性别**均衡。数据全程在本机浏览器内处理，不会上传。

## 使用方法

1. 双击打开 **`分班工具.html`**（单文件版，可直接拷贝到任何电脑使用，无需联网）
2. 拖入或选择学生名单 Excel（需包含：姓名、性别（男/女）、语文、数学、英语；其他列如毕业学校、学号会原样保留并跟随学生进入结果表）

   已验证可直接使用的表头格式：`姓名 | 性别 | 毕业学校 | 语文 | 数学 | 英语`

3. 工具自动识别列名（也可手动指定），并列出有问题的行（缺成绩、性别非法等，这些行不参与分班）
4. 填写班级数量 → 点击「开始分班」
5. 查看均衡度统计（每班人数、男女、各科平均分、班级间差距）和各班名单
6. 需要手动调整时点学生行的「调班」——默认**对调模式**：自动从目标班筛出同性别、总分最接近的学生换回来，均衡不受影响；每笔调整可撤销

   名单和调班弹窗都显示「原表行号」（学生在原始 Excel 中的行号），**遇到重名学生时用它区分是哪一个**
7. 点击「导出分班结果 Excel」：总名单（原表 + 班级列）+ 每班一个工作表 + 均衡统计表

同分学生顺序由「随机种子」决定，记下种子号即可复现同一份结果。

## 算法说明

1. 男生、女生分别按总分降序排序（同分随机打散）
2. 各自蛇形（S 形）发牌到各班，女生方向与男生镜像 → 保证性别、人数、总分基本均衡
3. 交换优化：在同性别学生间尝试跨班对调，只要能使各班「语/数/英/总分平均分与全体平均分的偏差」变小就采纳 → 三科平均分极差可收敛到 0.1 分以内
4. 交换只在同性别之间进行，人数与性别均衡始终不被破坏

## 文件说明

| 文件 | 说明 |
|---|---|
| `分班工具.html` | **最终交付的单文件工具**（内嵌全部依赖，离线可用） |
| `index.html` | 开发版页面（需与 `xlsx.full.min.js`、`algo.js` 同目录） |
| `algo.js` | 分班核心算法（页面与测试共用） |
| `xlsx.full.min.js` | SheetJS Excel 读写库 |
| `样例名单.xlsx` | 模拟测试数据（401 名有效学生 + 2 行脏数据） |
| `测试-用户表格式.xlsx` | 与实际使用表头一致的测试数据（姓名/性别/毕业学校/语文/数学/英语） |
| `scripts/gen_sample.js` | 生成样例名单：`node scripts/gen_sample.js` |
| `scripts/test_algo.js` | 算法均衡性测试：`node scripts/test_algo.js 8` |
| `scripts/build.js` | 打包单文件版：`node scripts/build.js`（改完 index.html/algo.js 后重新执行） |

## 隐私说明

本工具**完全在浏览器本地运行**，不含任何网络请求，学生数据不会离开你的电脑。仓库内的 `样例名单.xlsx`、`测试-用户表格式.xlsx` 均为脚本随机生成的**虚构数据**，不含任何真实学生信息。

仓库的 `.gitignore` 已配置为自动排除 `真实名单*.xlsx`、`*新生名单*.xlsx`、`分班结果*.xlsx` 等文件名，避免真实学生名单被误提交。**请勿把含真实学生信息的表格提交到公开仓库。**
